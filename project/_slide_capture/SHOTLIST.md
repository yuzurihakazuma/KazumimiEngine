# 進捗報告スライド用 撮影指示書（Claude Code 向け）

このフォルダ（`project/_slide_capture/`）は、進捗報告スライド「表と裏で遊べる、クラフトのステージを作る」の画面枠に入れる映像・画像を集めるための**一時フォルダ**です。発表が終わったら消してかまいません。中の画像・動画は `.gitignore` でコミットされないようにしてあります。

---

## 0. Claude Code へのお願い（ルール）

- **ゲームのコード（engine/・game/）は変更しない。** 撮影は外から行う（下の「撮り方 B」）。撮影機能をエンジンに入れる場合は、別の企画書（撮影機能 企画書）に沿って本人が実装する。
- 撮った物は、下の表の **ショットID のフォルダ** に、決めたファイル名で置く。
- 失敗した撮り直しや、切り出す前の長い録画は `_raw/` に置く。
- 終わったら、各フォルダに何を置いたかを、このファイルの「6. 撮影結果」に追記する。

## 1. 共通の決まり

| 項目 | 決まり |

## 2. ゲームの操作メモ（撮る人向け）

- ウィンドウのタイトルは **`CG2`**。初期サイズは 1920×1080。
- **F1**：エディタの表示を切り替える。ゲーム画面だけを撮る時は F1 でエディタを消す。
- **F2**：エディタの UI をドック⇔アイコンに切り替える。
- 環境変数 **`CG2_DEBUG_KEYS`** を付けて起動すると、**F8 でカメラを反転**できる（裏世界をすぐ見たい時用）。
- 舌：E ／ 卵を産む：左Ctrl ／ 吐き出す：F ／ 卵を構えて投げる：Q 長押し→離す。
- stage1 の **？スイッチ** は、レール 2 の 8.7m 付近（ワールド座標 およそ (17.0, 4.6, 7.42)）。卵を当てると裏へ回る。
- **同じ動きで撮り直したい時**：パネル「乗り換えデバッガ」の「入力の記録を始める」→ 遊ぶ →「記録を止める」→「同じ所から再生」。再生中に録画すれば、同じ動きを何度でも撮れる（記録はアプリを閉じると消える）。

## 3. 撮り方

### 撮り方 A：エンジンの撮影機能（まだ無い）
撮影機能 企画書のとおりに実装されたら、ゲーム画面だけ（ImGui なし）をきれいに撮れる。今は無いので B を使う。

### 撮り方 B：ffmpeg でウィンドウを録画する（今はこちら）
ffmpeg が無ければ入れる：`winget install Gyan.FFmpeg`

**ウィンドウを録画（ImGui も写る）**
```
ffmpeg -f gdigrab -framerate 30 -i title=CG2 -c:v libx264 -preset veryfast -crf 18 -pix_fmt yuv420p _raw/S01_take1.mp4
```
（止める時は ffmpeg のウィンドウで q）

**ゲーム画面だけにしたい時**：F1 でエディタを消してから録画する。

**必要な所だけ切り出す（開始 12 秒から 30 秒間）**
```
ffmpeg -ss 12 -t 30 -i _raw/S01_take1.mp4 -c:v libx264 -crf 18 -pix_fmt yuv420p -an S01_progress/S01_progress.mp4
```

**GIF にする（幅 960、15fps、色数を最適化）**
```
ffmpeg -ss 3 -t 6 -i _raw/S02_take1.mp4 -vf "fps=15,scale=960:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" S02_flip/S02_flip.gif
```

**静止画を1枚取り出す（8.5 秒の所）**
```
ffmpeg -ss 8.5 -i _raw/S03_take1.mp4 -frames:v 1 S03_road_after/S03_road_after.png
```

## 6. 撮影結果（撮ったら追記）

撮影日 2026-11-08。撮り方は「撮り方 A」（エンジンの撮影機能 ScreenCapture）を使った。
- ゲーム画面の物：キー入力をテイクにして「再生しながら録画」（固定コマ送り 60fps → GIF は 15fps に間引き）。ImGui なし、HUD（左上の札）はあり
- エディタごとの物（S05〜S08）：ウィンドウを外から 15fps で撮り、窓のふちを除いて真ん中を 16:9 に切り抜いた
- 頼まれたとおり「基本 GIF」で用意した。S01・S02・S09・S10 は MP4 も置いてある
- 撮る前に直した物：SDF の操作説明の看板を消した・地面のマス目の線（グリッド表示と地面ブロックの継ぎ目）を消した・卵が地面にめり込むのを直した・
  緑の段差をばねにして高く跳べるようにした・裏の世界（地面と飾りとコース）を作った・裏から見る時に表の物が画面をふさがないようにした・

# 進捗報告スライド用 撮影指示書 v2（Claude Code 向け）

進捗報告スライド（13枚。卵の奥投げコンボと背景エディタの2本柱）に使う映像を、**今のゲームで全部撮り直す**ための指示書。
前の指示書（`SHOTLIST.md`）で撮った S01〜S11 は古い動き（卵が跳ね返るコンボなど）なので、使わない。

撮った物は、このフォルダ（`project/_slide_capture/v2/`）の、ショットIDの名前のフォルダに置く。

---

## 0. ルール

- **ゲームのコード（engine/・game/）は変えない。** 撮るだけ
- **マップを保存しない。** 背景エディタの撮影でステージを変えても、保存しない（Ctrl+S を押さない）。保存が必要な B11 だけは、撮る前に `resources/map/stage1_backdrop_edit.json` を `_slide_capture/v2/_backup/` にコピーし、撮った後に元に戻す
- **デバッグ表示は消す。** 「当たり判定を表示」は OFF。ゲームの画面だけを撮るショットは F1 でエディタを消す
- 撮り直しや、切り出す前の長い録画は `_raw/` に置く
- 終わったら、この指示書の「5. 撮影結果」に追記する

## 1. 共通の決まり

| 項目 | 決まり |
|---|---|
| 縦横比 | すべて 16:9 |
| GIF | 幅 960px、15fps、長さ 3〜8 秒。**1 本 8MB 以下**（超える時は 12fps か幅 800 に下げる） |
| 動画 | P01 だけ MP4 も置く（1920×1080、30fps、音なし） |
| 静止画 | 各 GIF の一番分かりやすいコマを PNG（1920×1080）でも 1 枚置く |
| ファイル名 | `ID_内容.gif` / `.png` / `.mp4`（例：`B04_brush.gif`） |
| 写すもの | 「ゲームのみ」＝F1 でエディタを消す／「エディタごと」＝背景エディタのパネルと Game View の両方が見える |

GIF にするコマンドと、録画の仕方は `SHOTLIST.md` の「3. 撮り方」と同じ。

## 3. 背景エディタのショット（3章 背景エディタ）

パネル「背景エディタ (Backdrop)」で、「背景を編集する」を ON にして撮る。すべて**エディタごと**。

| ID | 撮る物 | 撮り方のメモ |
|---|---|---|
| B01 | 選ぶ | 「選ぶ」でクリック → Shift で追加 → 空いた所をドラッグで範囲選択 → つかんで地面の上を動かす |
| B02 | ギズモ | 選んだ木を「移動」「回転」「拡縮」のギズモで動かす |
| B03 | 置く | パレットで木を選び、地面を何回かクリックして置く。「向きをばらす」で向きが少しずつ違う所 |
| B04 | ブラシ | 「ブラシ」で草むら・花畑を塗る。ブラシの大きさが分かる角度で |
| B05 | 消しゴム | 「消しゴム」（草・花だけ消す ON）で、木は残って草花だけ消える所 |
| B06 | 地面を塗る | 「地面」で 草 → 道（紙）→ 土（段ボール）→ 穴にする、を順に塗る |
| B07 | 段の上げ下げ | 「地面」の「段を上げる」「段を下げる」で、地面の高さが変わる所 |
| B08 | 道を線で引く | 「道を線で引く（つながった道）」で線を引いて、帯と丸のつながった道ができる所 |
| B09 | 右クリックメニュー | 物を右クリック →「同じ種類を全部選ぶ」→「地面に合わせる」 |
| B10 | 元に戻す・やり直す | いくつか置いた後、Ctrl+Z で戻り、Ctrl+Y でやり直す |
| B11 | 手直しが残る | 木を手で 2〜3 本足して保存 →「自動配置をやり直す」→ 足した木が残っている所。**撮る前にバックアップ、撮った後に元に戻す** |
| B12 | ドラッグ＆ドロップで置く | パレット（またはファイルエディタ）から、モデルを Game View へドラッグして置く |

## 4. 背景エディタとコンボのショット（3章 背景エディタとコンボ）

| ID | 撮る物 | 写すもの | 撮り方のメモ |
|---|---|---|---|
| X01 | コンボの道を見せる | エディタごと | 「コンボの道を見せる」を ON にして、木を選ぶと、はじける順の線（青＝左のふち・白＝真ん中・橙＝右のふち）が出る所。別の木を選ぶと線が変わる |
